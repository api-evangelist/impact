impact.com is a partnership management platform for affiliate, creator, influencer and customer-referral programs. It publishes four REST API personas - Brand v14, Partner v16, Agency v3 and Advocate v13 - across 69 OpenAPI 3.1 documents and 245 operations, a remote OAuth 2.1 MCP server at mcp.impact.com, first-party agent skills, an Advocate GraphQL endpoint, webhook and postback event delivery, and an agent-readable developer portal that serves llms.txt, per-page markdown and a live documentation question interface.

**Areas:** Affiliates · Partnerships · Performance Marketing · Commissions · Tracking · Creator Economy · Partner Management · Referrals · Attribution · Payouts · Marketing · Advertising

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Impact: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
